# ship-cli 验证报告

日期：2026-10-09。对象：ship-cli 0.1.0 与本地 v-cli 0.2.14。已完成官方契约核验、源码改造及本地安装验证。

## 最终结构

- commands：选择工程与命令流程，离线门禁、结果输出。
- core：严格配置 / schema、真实路径隔离、进程生命周期、分块脱敏、结构化错误。
- steam：VDF、Steam Guard、steamcmd 调用、按 AppID / BuildID 判定完成、本地文件检查。
- wx：game.json 结构、packOptions / ignores 过滤、源码预算、官方 SDK 调用及完成记录校验。
- 配套：schema、插件清单、随包 Agent 规范、官方调研文档、prepack、CI、安装冒烟。

配置使用明确字段，无 ciArgs 透传或旧凭据别名；旧字段会被 schema 拒绝。v-cli 通过官方白名单与可选 peer 声明发现 ship，不需要本地插件包装或解析环境变量。

本次没有真实登录或上传 Steam，也没有调用微信生成实际可扫码的预览。SDK 流程测试使用本地模拟 SDK 与虚构测试密钥；Steam 解析使用日志样本。实际 App / Depot 权限、账号有效性、微信上传白名单、编译结果及二维码扫码须用真实工程验证。
