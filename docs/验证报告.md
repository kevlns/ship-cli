# Vant 游戏分发验证指南

## 定位

说明工具验证与真实平台验收的边界，不将模拟测试结果作为账号或平台发布成功的证明。

## 前置条件

已构建游戏产物，配置通过 schema 校验；按需准备 steamcmd、Steam App/Depot 权限或微信工程、上传私钥与 miniprogram-ci。

## 操作流程

1. 运行 `npm run check` 检查构建、类型、测试、lint 和发布包；运行 `npm run test:package` 验证隔离安装。
2. `config validate` 检查字段与目录边界，`doctor --json` 读取逐项检查结果。
3. Steam 先生成 VDF，执行 preview 和本地 test；获得上传授权后执行 push，并核对当前 AppID 与 BuildID。
4. 微信先 validate，再按授权生成 preview 二维码或 push 开发版；核对实际二维码文件、SDK 结果和平台后台记录。

## 结果验证

模拟 SDK 与日志样本只证明本地协议处理。账号权限、上传白名单、编译结果和扫码效果需要真实工程核验。源码体积标记 filtered-source-estimate，不等于实际编译包大小。无法确认的 Steam 输出返回 STM_BUILD_UNKNOWN_OUTCOME，不推断成功。正式发布、提审与分支切换按平台要求处理。
